# NHOM04_DOANCUOIKY

## 1. Giới thiệu
Đề tài: Ứng dụng Chat có tích hợp tính năng truyền tệp tin 1-1.

Ứng dụng cho phép hai người dùng kết nối, trao đổi tin nhắn
và truyền tệp tin trực tiếp với nhau.

## 2. Công nghệ sử dụng
- Ngôn ngữ: Java
- Giao diện: Java Swing (dự kiến)
- Giao tiếp mạng: TCP Socket
- IDE: NetBeans

## 3. Cấu trúc dự án
- `Chat1v1/`: Mã nguồn ứng dụng Java.
- `.gitignore`: Các tệp và thư mục Git không cần theo dõi.

## 5. Cách chạy chương trình
1. Clone repository về máy.
2. Mở dự án `Chat1v1` bằng NetBeans.
3. Chạy chương trình theo hướng dẫn sau khi hoàn thiện.
